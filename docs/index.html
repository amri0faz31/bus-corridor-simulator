About and how to use

Choose demand, running-time variability, and a maximum hold. Start advances both simulations together. The base scenario uses no holding. The other panel tries for an 80-second release gap before Market.

Circles are buses. A ring marks one waiting for the Market berth. An orange circle marks a bus waiting at the control point. The chart position between stops is interpolated from event timestamps.

Use Load notebook reference to replay the exact deterministic disruption from the notebook. The reference check compares completed trips and recorded timings. The random preview uses one browser-seeded run. The notebook uses repeated paired runs for confidence intervals.
