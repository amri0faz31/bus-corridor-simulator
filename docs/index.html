About these runs

All panels share the same bus schedule, passengers and road travel times. At 1×, one real second advances the clock by one simulated second.

The published-parameter scenario uses five link means from Herath et al. The plot shows stop order. Faster boarding assumes 20% less time per boarding passenger at every stop. Holding aims for an 80-second release gap before Market.

The original road disruption is a separate two-policy replay. Changing the demand, variability or hold cap opens a single published-parameter preview. The notebook runs the repeated experiment.
