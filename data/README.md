# Data and generated outputs

The model uses synthetic passenger demand, running times and route geometry. See the [experiment design](../EXPERIMENT_PLAN.md) and [references](../REFERENCES.md). No raw field data are distributed.

- `paired-replications.csv` has one row per run with the scenario, seeds, policy, passenger counts and delay measures.
- `policy-effects.csv` has one row per scenario and metric, with policy means and a paired 95% interval for holding minus baseline. Timing measures are seconds. Platform, journey and passenger-weighted delay components are seconds per passenger. Market queue and control means are seconds per bus. Queue share is a fraction. Headway standard deviation is in seconds.
- `browser-reference.json` contains the Python timings and trip counts for the deterministic browser reference. The browser copy in `docs/reference.js` is checked by the parity test.

All three files are regenerated by the notebook.
